# 0003. Спецификация из telegram-bot-api-spec

2026-10-08.

**Решение.** Редактор строится из машиночитаемого `api.json` проекта [PaulSonOfLars/telegram-bot-api-spec](https://github.com/PaulSonOfLars/telegram-bot-api-spec), который пересобирается с core.telegram.org при каждом релизе Bot API. Студия скачивает его при запуске, раз в 12 часов и по кнопке ↻. Копию в репозитории обновляет `make spec-update`, по понедельникам это делает рутина Claude.

**Почему.** Свой парсер HTML-страницы Telegram ломался бы при каждой смене вёрстки. Готовый JSON уже разобран и обычно появляется в день релиза. Без интернета работает встроенная копия.

**Отказались.** От парсинга core.telegram.org своими силами. Открыт вопрос у треда архитектуры: проверка целостности стороннего источника.
